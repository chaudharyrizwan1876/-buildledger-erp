# Screenshots

Drop your own screenshots here with these exact filenames and they'll automatically show up in
the main `README.md` on GitHub:

- `dashboard.png`
- `sales.png`
- `customers.png`
- `reports.png`

Recommended: run the app maximized, take a clean screenshot of each screen with a bit of real
(or realistic-looking) demo data in it, and save as PNG. 1600px wide or so looks good on GitHub.
